# Nurunnahar nody - Profile Website

A modern, responsive profile website showcasing professional information and skills.

## Project Details

**Name:** Nurunnahar nody  
**Education:** Bachelor of Science in Computer Science  
**Location:** Denmark

## Files

- **index.html** - Main HTML file with profile information and structure
- **styles.css** - Styling and responsive design
- **README.md** - Project documentation

## Features

- 🎨 Modern, gradient-based design
- 📱 Fully responsive layout (desktop, tablet, mobile)
- 🎯 Professional presentation of:
  - Personal information
  - Educational background
  - Skills overview
  - Location details
- ✨ Smooth hover effects and transitions
- 🚀 Easy to customize and extend

## How to Use

1. Open `index.html` in a web browser to view the profile website
2. Edit `index.html` to update personal information
3. Customize `styles.css` to change colors, fonts, or layout
4. Add more sections as needed

## Customization

### Change Colors
Edit the gradient colors in `styles.css`. Currently using:
- Primary: `#667eea` (Blue/Purple)
- Secondary: `#764ba2` (Purple)

### Add More Content
Add new sections in `index.html` between the existing sections. Follow the same HTML structure and apply appropriate CSS classes.

### Add Contact Information
You can add a contact section with links to email, LinkedIn, GitHub, etc.

## Browser Support

Works on all modern browsers:
- Chrome/Edge
- Firefox
- Safari
- Mobile browsers
